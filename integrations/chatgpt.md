# ChatGPT

## Option A: connector (MCP)
Settings → Apps & Connectors → Advanced → enable Developer mode → Create →
URL `https://tips33.vercel.app/mcp`, authentication: none.

## Option B: Custom GPT (works for anyone you share it with)
1. Explore GPTs → Create → Configure.
2. Actions → Create new action → Import from URL: `https://tips33.vercel.app/openapi.json`. Authentication: none.
3. Privacy policy: `https://tips33.vercel.app/privacy`
4. Instructions: paste the content of [`chatgpt-instructions.txt`](chatgpt-instructions.txt).
